# AD. — Aditya Dutta · Life Journey Portfolio

Immersive single-page storytelling portfolio. Vertical scroll drives a horizontal world; a Lottie character walks while you scroll.

## Stack

- Next.js (App Router) · TypeScript · Tailwind CSS
- GSAP + ScrollTrigger · Lenis · Framer Motion · Lottie

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Assets

Placeholder SVGs ship under `public/illustrations/`. Replace with your PNGs and Lottie — see `public/illustrations/README.md` and `docs/JOURNEY_PORTFOLIO_PLAN.md`.
